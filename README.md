# КД каркаса для Archicad 30

Плагин для палитры [Tapir](https://github.com/ENZYME-APD/tapir-archicad-automation):
разбирает деревянный каркас ArchiFrame (`ArchiFramePlank`) открытого проекта на
марки и выпускает комплект КД:

1. Ведомость чертежей
2. СП-1 «Общая спецификация»: марка, слой, сечение, длина, кол-во, миниатюра
3. Листы деталей по слоям: каждая марка с размерами, углами запилов и
   спецификацией слоя

Результат — PDF-файл и/или листы прямо в книге макетов Archicad (на вашем
мастер-макете, со штампом и сквозной нумерацией), общий PDF — набором публикации.

## Установка (один раз)

Скопируйте папку установщика и запустите **`Установить.bat`** (можно из сетевой папки).
Он проверит/поставит:

| | |
|---|---|
| Archicad 30 | должен быть установлен |
| Tapir для AC30 | скачивается с GitHub, права администратора — только на копирование в папку Archicad |
| uv | `winget install astral-sh.uv`; Python и pymupdf uv скачивает сам |
| Этот репозиторий | подключается к палитре Tapir — **дальше плагин обновляется с GitHub сам** |

Журнал установки: `%TEMP%\kd_install.log`. Удаление: `Удалить.bat`.

## Запуск

Archicad 30 → проект с каркасом ArchiFrame → **палитра Tapir → `KD_Karkas_PDF.py` → ▷**.
Если скрипта нет в списке — пункт «Reload scripts…» в списке палитры.

**Обновление:** окно само сверяет версию с GitHub и пишет «Доступна версия X»;
кнопка **«Обновить»** скачивает свежие файлы и перезапускает окно.

| Режим | Что делает |
|---|---|
| Только PDF-файл | быстро, проект не меняется |
| Листы в Archicad | подмножество «КД каркаса (авто)» в книге макетов (перед пересозданием спросит подтверждение) |
| Общий PDF из готовых листов | публикует листы Archicad, ничего не перестраивая |
| Пересоздать листы + общий PDF | всё вместе |
| Марки и параметры в свойства досок | для интерактивного каталога Archicad (ниже) |

Доски должны «читаться»: установлен ArchiFrame или проект `.pla` с вложенной
библиотекой (сам аддон тогда не нужен).

## Интерактивный каталог

Режим «Марки и параметры в свойства досок» присваивает доскам позицию
«Деталь каркаса» в отдельной системе классификации «КД каркаса» (классификацию
ARCHICAD не трогает) и заполняет группу свойств **«КД каркаса»**: Марка, Группа,
Сечение, Длина мм, Кол-во в марке, Примечание. Свойства не бывают у
неклассифицированных элементов — поэтому своя классификация.

Схему каталога API Archicad создать не умеет — настраивается один раз
(лучше в шаблоне офиса): *Документ → Каталоги → Параметры Схемы → Новая*;
критерий «Классы / КД каркаса - 1» в ветви «КД-1 Деталь каркаса»; поля — группа
«КД каркаса» (Σ не включать); в самом каталоге флажок «Объединить Элементы».
Дальше: изменили модель → этот режим → каталог пересчитался.

**Каталог на листах.** Если в проекте есть каталог с ID из `archicad.schedule.id`
(по умолчанию «КД-СП»), режим «Листы в Archicad» сам обновляет свойства и ставит
каталог на листы сразу после СП-1: фрагментами по 2 колонки на A3, с повтором
шапки. Режется ровно по строкам — высота строки каталога должна быть одинаковой
(`row_height_mm`, по умолчанию 6 мм).

## Настройки

Умолчания — `tapir-scripts/kd_plugin/config.default.json` (обновляются вместе с плагином).
Свои — **`%APPDATA%\kd_plugin\config.json`**, достаточно указать отличия, например:

```json
{
  "company": "Моя компания",
  "layer_prefixes": { "Ферма": "F", "Колонны, Столбы": "K" },
  "archicad": { "master_a3": "А3 - А - Ф3", "publish_subsets": ["КД каркаса (авто)", "3D-виды"] }
}
```

- `layer_prefixes` — префикс марки по слою (общий префикс = сквозная нумерация), остальные — автопрефикс
- `layer_order`, `detail_sheet_groups` — порядок слоёв, несколько слоёв на одном листе
- `archicad.skip_layers` — что не выпускать
- `archicad.master_a3/master_a4` — мастер-макеты (нет такого — первый подходящий по формату)
- `archicad.subset_name`, `layer_name`, `publisher_set`, `publish_subsets`, `font_index`

## Оформление (ГОСТ)

Рамка и штамп — мастер-макет проекта; шрифт — шрифт штампа мастера (в PDF без
Archicad — GOST type B); высоты шрифта 2,5/3,5/5/7 мм (ГОСТ 2.304); линии 0,5/0,18 мм
(ГОСТ 2.303); масштабы ГОСТ 2.302; размеры по ГОСТ 2.307.

## Как читается доска ArchiFrame

`iLen` — длина опорной линии, `iWidth`/`iHeight` — сечение, `iMatName`, `iMc` —
обработки по 16 чисел: 101/201 — запил начала/конца (`[1]` угол в плане, `[2]` по
высоте, 90° — без запила), 301 — произвольный рез (пока не рисуется, у детали
пометка «см. 3D»). Подробнее — `kd/archicad.py`.

## Разработка

```
tapir-scripts/            ← эту папку палитра Tapir скачивает с GitHub
  KD_Karkas_PDF.py        ← кнопка (окно)
  kd_plugin/kd/           ← ядро: сбор, марки, листы, PDF, макеты Archicad
installer/                ← install.bat / install.ps1 / make_dist.py
```

```
cd tapir-scripts/kd_plugin
python -m kd --demo                       # PDF по демо-данным
python -m kd --archicad [--layouts] [--publish]
python ../../installer/make_dist.py       # собрать папку-установщик в ../dist
```

Выпуск версии: поднять `__version__` в `kd/__init__.py`, закоммитить, запушить —
палитры Tapir у пользователей подтянут изменения сами.

## Ограничения

- Резы `iMc 301` не рисуются.
- 3D-виды и узлы — ваши макеты Archicad; их подмножество можно добавить в `publish_subsets`.
- `--write-marks` (запись марок в ID элементов) не проверен.
