КД каркаса для Archicad 30 — установка и обновление
=====================================================

ПЕРВАЯ УСТАНОВКА
  1. Запустите «Установить.bat» (можно прямо из сетевой папки).
  2. Перезапустите Archicad 30 и откройте проект с каркасом ArchiFrame
     (установлен ArchiFrame или проект .pla с вложенной библиотекой).
  3. Палитра Tapir -> список скриптов -> KD_Karkas_PDF.py -> кнопка ▷.

ЕСЛИ ПЛАГИН УЖЕ СТОИТ

  а) Ставили старым установщиком (кнопка лежит в Документы\Tapir\custom-scripts)
     или не уверены:
       запустите «Установить.bat» один раз — он перенесёт ваши настройки,
       уберёт старую кнопку и подключит обновления с GitHub.
       Затем перезапустите Archicad.

  б) Стоит версия 1.1.x (в заголовке окна «КД каркаса v1.1.x»):
       1. Палитра Tapir -> список скриптов -> «Reload scripts…»
       2. Выберите KD_Karkas_PDF.py -> ▷
       3. В окне нажмите «Обновить» — окно откроется заново версией 1.2 или новее.
       (один раз)

  в) Стоит 1.2.0 или новее:
       ничего делать не нужно. Когда выйдет новая версия, внизу окна появится
       «Доступна версия X — нажмите «Обновить»».

РЕЖИМЫ В ОКНЕ
  • Только PDF-файл — быстро, проект не меняется.
  • Листы в Archicad — листы в книге макетов, подмножество «КД каркаса (авто)».
    Если листы уже есть, окно спросит: ручные правки на них пропадут.
  • Общий PDF из готовых листов — Archicad публикует существующие листы.
  • Пересоздать листы + общий PDF — всё сразу.
  • Марки и параметры в свойства досок — для интерактивного каталога (см. ниже).

ИНТЕРАКТИВНЫЙ КАТАЛОГ (спецификация, которая обновляется сама)
  1. В окне плагина выберите «Марки и параметры в свойства досок» -> «Выпустить КД».
     Доскам присваивается классификация «КД каркаса / Деталь каркаса»
     (классификацию ARCHICAD это не трогает) и группа свойств «КД каркаса»:
     Марка, Группа, Сечение, Длина мм, Кол-во в марке, Примечание.
  2. Один раз на проект (или в шаблоне офиса) создайте схему каталога:
     Документ -> Каталоги -> Параметры Схемы… -> «Новая…»
       ID «КД-СП», имя «КД каркаса — спецификация», тип «Элементы» -> OK
       • «Добавить Критерии…» -> в поиске «КД каркаса» -> строка
         «Классы / КД каркаса - 1» -> Добавить
         (получится: КД каркаса - 1 — в ветви — КД-1 Деталь каркаса)
       • «Добавить Поля…» -> поиск «КД каркаса» -> по очереди: Марка, Группа,
         Сечение, Длина мм, Кол-во в марке, Примечание (Σ не включать)
       • OK. Откройте каталог: Документ -> Каталоги -> «КД-СП …»
       • Слева в панели формата включите «Объединить Элементы» —
         одна строка на марку. Ширину столбца «Группа» потяните мышью.
  3. На листы каталог ставит сам режим «Листы в Archicad» — фрагментами
     после общей спецификации (по 2 колонки на A3, шапка повторяется).
  Изменили модель -> снова этот режим -> каталог пересчитается сам.

НАСТРОЙКИ
  %APPDATA%\kd_plugin\config.json — префиксы марок, мастер-макеты, что публиковать.
  Обновления этот файл не трогают.

ЕСЛИ ЧТО-ТО НЕ ТАК
  Журнал установки: %TEMP%\kd_install.log — пришлите его.
  Удаление: «Удалить.bat» (Tapir и uv остаются).
