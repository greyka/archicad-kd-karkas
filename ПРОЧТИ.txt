ПЛАГИНЫ ДЛЯ ARCHICAD 30
=======================

УСТАНОВКА НА КОМПЬЮТЕР
----------------------
1. Скопируйте всю папку плагинов на компьютер (или запустите из сетевой папки).
   Последняя версия: https://github.com/greyka/archicad-kd-karkas/releases
   (Source code (zip) -> распаковать).
2. Запустите «Установить.bat».
3. Перезапустите Archicad -> палитра Tapir -> «KD_Karkas_PDF.py (Плагины Archicad)» -> Run.

Что ставится (один раз, общее для всех плагинов):
  • Tapir для Archicad 30 — с GitHub, права администратора только на копирование
    в папку Archicad;
  • uv — запускает Python-скрипты, сам скачивает Python и pymupdf.

Куда ставится:  C:\ArchicadPlugins\
                  tapir-scripts\   — плагины (палитра Tapir видит эту папку)
                  _setup\          — служебные файлы
                  settings.ini     — ваши настройки
(если в C:\ писать нельзя — в %LOCALAPPDATA%\ArchicadPlugins)

После установки папку установщика можно удалить — работает копия
из C:\ArchicadPlugins.


МЕНЕДЖЕР ПЛАГИНОВ И НАСТРОЙКИ
-----------------------------
«Менеджер плагинов Archicad» — ярлык на рабочем столе и в меню «Пуск»
(или кнопка «Настройки и версия…» в окне плагина):
  • Плагины            — что установлено, подключить в Archicad заново;
  • Настройки          — всё, что можно настроить, по разделам;
  • Версия и обновление — установленная версия, новая на GitHub, «Обновить»;
  • Что нового         — журнал изменений (CHANGELOG.md).
Настройки — C:\ArchicadPlugins\settings.ini (можно править Блокнотом).
Расширенные (префиксы марок, порядок слоёв) — %APPDATA%\kd_plugin\config.json,
кнопка «Расширенные (config.json)» в менеджере. Обновления эти файлы не трогают.


ВЕРСИИ И ОБНОВЛЕНИЕ С GITHUB (автоматически)
--------------------------------------------
Номер версии — в файле VERSION, список изменений — CHANGELOG.md.
Компьютер сам проверяет обновления при каждом входе в Windows (ярлык
«Обновление плагинов Archicad» в Автозагрузке; выключается в менеджере).
По умолчанию ставятся только ВЫПУЩЕННЫЕ версии (релизы GitHub).
Вручную: менеджер -> «Версия и обновление» -> «Обновить», или «Обновить.bat».
Если Archicad открыт — в палитре Tapir выберите «Reload scripts…».

Для разработчика (выпуск версии):
  1. правите файлы в репозитории;
  2. в CHANGELOG.md добавляете раздел «## 1.6.0 — дата» со списком изменений;
  3. python _setup\release.py 1.6.0
     (запишет VERSION, коммит, тег v1.6.0, push, релиз на GitHub).
  Новые настройки описываются в _setup\settings_schema.json (ключ "path" —
  куда значение попадает в конфиг плагина) — менеджер сам покажет поля.
  Менеджер собирается: powershell -File _setup\manager\build.ps1


КД КАРКАСА (KD_Karkas_PDF.py)
-----------------------------
Режимы в окне:
  • Только PDF-файл — быстро, проект не меняется.
  • Листы в Archicad — листы в книге макетов, подмножество «КД каркаса (авто)».
    Если листы уже есть, окно спросит: ручные правки на них пропадут.
  • Общий PDF из готовых листов — Archicad публикует существующие листы.
  • Пересоздать листы + общий PDF — всё сразу.
  • Марки и параметры в свойства досок — для интерактивного каталога.

Интерактивный каталог (спецификация, которая обновляется сама):
  1. Режим «Марки и параметры в свойства досок»: доскам присваивается
     классификация «КД каркаса / Деталь каркаса» (ARCHICAD не трогается)
     и группа свойств «КД каркаса».
  2. Один раз на проект (или в шаблоне офиса) создайте схему каталога:
     Документ -> Каталоги -> Параметры Схемы… -> «Новая…»
       ID «КД-СП», имя «КД каркаса — спецификация», тип «Элементы»
       • «Добавить Критерии…» -> поиск «КД каркаса» -> «Классы / КД каркаса - 1»
       • «Добавить Поля…» -> поиск «КД каркаса» -> Марка, Группа, Сечение,
         Длина мм, Кол-во в марке, Примечание (Σ не включать)
       • в самом каталоге включите «Объединить Элементы»
  3. На листы каталог ставит режим «Листы в Archicad» — после общей
     спецификации, по 2 колонки на A3, шапка повторяется.

Доски должны «читаться»: установлен ArchiFrame или проект .pla с вложенной
библиотекой.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
Журнал установки: %TEMP%\archicad_plugins_install.log — пришлите его.
Плагин пропал из палитры: менеджер -> «Подключить в Archicad заново».
Удаление: «Удалить.bat» (Tapir, uv и settings.ini остаются).
