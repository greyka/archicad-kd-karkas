1. Светофор

Безопасно — проект не меняется

  • КД каркаса → «Только PDF-файл»
  • КД каркаса → «Общий PDF из готовых листов» (только публикует)
  • Площади поверхностей (пишет отчёт HTML/CSV)
  • Менеджер: настройки, проверка и установка обновлений, «Сообщить о проблеме…»

Меняет проект — сохранитесь до запуска

  • КД каркаса → «Листы в Archicad» — книга макетов
  • КД каркаса → «Пересоздать листы + общий PDF»
  • КД каркаса → «Марки и параметры в свойства досок» — сама модель

Только при закрытом Archicad

  • «Установить.bat», «Удалить.bat»
  • Менеджер → «Подключить в Archicad заново»
  • Правка Документы\Tapir\config.json

Иначе Archicad может упасть. Установка и удаление сами откажутся работать при открытом Archicad.

2. Чего не делать

  • Не запускайте «Листы в Archicad» / «Пересоздать листы», если на листах подмножества «КД каркаса (авто)» есть ручные правки, которые нужно сохранить: листы удаляются и строятся заново. Нужны правки — скопируйте листы в другое подмножество или переименуйте подмножество в настройках.
  • Не запускайте режимы, меняющие проект, на чужом проекте без договорённости: «Марки и параметры» записывает свойства в каждую доску, «Листы» добавляет десятки листов.
  • Не сохраняйте проект после пробного запуска, если результат не нужен: закройте без сохранения — файл на диске останется прежним. (Отменять сотни изменений через «Отменить» долго.)
  • Не устанавливайте, не удаляйте и не жмите «Подключить в Archicad заново» при открытом Archicad.
  • Не правьте файлы в C:\ArchicadPlugins (кроме settings.ini) — обновление их перезапишет. Настройки меняйте в менеджере.
  • Не запускайте файлы из tapir-scripts\kd_plugin\ — это служебные модули, плагины — только из менеджера или палитры Tapir.
  • Не переносите папку C:\ArchicadPlugins — палитра Tapir и ярлыки ссылаются на неё. Нужно в другое место — «Удалить.bat», затем «Установить.bat».
  • Не открепляйте «Реестр отчётов» в чате Telegram-бота @lider_house_debug_bot — по нему разработчик находит отчёты об ошибках.
  • Не нажимайте «Выпустить КД» второй раз, пока идёт работа (кнопка неактивна, внизу окна — что делается). Листы строятся 2–3 минуты, в это время Archicad «задумчив» — это нормально.

3. Как запустить плагин

  1. Откройте проект в Archicad.
  2. Запуск — любым способом:
    • Менеджер плагинов Archicad (ярлык на рабочем столе) → вкладка «Плагины» → выделите строку → «Запустить» (или двойной клик по строке);
    • палитра Tapir в Archicad → «KD_Karkas_PDF.py (Плагины Archicad)» или «Ploshchadi_Poverkhnostey.py» → Run.
  3. Окно плагина появляется через 5–10 секунд (запускается Python).
  4. Если открыто несколько Archicad, плагин спросит, с каким проектом работать. Если Archicad не открыт — скажет об этом и закроется.
  5. Само окно ничего не делает — работа начинается только по кнопке («Выпустить КД», «Посчитать»).

4. КД каркаса — режимы

Плагин берёт доски ArchiFrame (ArchiFramePlank) открытого проекта, группирует их по слою (слой = группа: «Этаж 1 - стена 1», «Ферма»…), одинаковые по форме доски сливает в одну марку (префикс группы + номер, например ES-3) и выпускает КД как образец «КД Навес».

РежимЧто делаетПроектВремя*Когда
Только PDF-файл Рисует комплект сам и сохраняет PDF: ведомость, СП-1, листы деталей по группам (развёртки с размерами, углы запилов, мини-спецификация). Файл — рядом с проектом, «КД <проект>.pdf»; после выпуска открывается. не меняется~20 с Быстро посмотреть / отправить КД. Можно запускать сколько угодно.
Листы в Archicad Создаёт подмножество «КД каркаса (авто)» в книге макетов: листы на ваших мастер-макетах (A3 «А3 - А - Ф3 (!!! 1 !!!)», ведомость A4 «А4 - К - Ф3»), чертежи деталей на своём слое «КД - чертежи (авто)», куски интерактивного каталога «КД-СП» на листах общей спецификации. PDF не создаёт. книга макетов~2 мин Когда КД нужна внутри проекта (штамп, нумерация, правка руками).
Общий PDF из готовых листов Публикует уже построенные листы подмножества одним PDF через набор публикации Archicad. Ничего не перестраивает. не меняется~1 мин После «Листов в Archicad» и ручных правок на листах.
Пересоздать листы + общий PDF «Листы в Archicad», затем «Общий PDF» — за один раз. книга макетов3–4 мин Каркас поменялся, нужен свежий комплект в проекте и в PDF.
Марки и параметры в свойства досок Записывает в каждую доску классификацию «КД каркаса / КД-1 Деталь каркаса» и свойства группы «КД каркаса»: Марка, Группа, Сечение, Длина мм, Кол-во в марке, Примечание. Ничего не рисует. модель (свойства)~25 с Перед «Листами», если на листах нужен интерактивный каталог; после правок каркаса.

* Время — на модели ~900 досок / 170 марок / 45 листов.

Поля окна

  • Объект (в штампе) — название в штампе PDF (по умолчанию — имя проекта).
  • Файл PDF — куда сохранить PDF.
  • Только выделенные элементы — взять только выделенные в Archicad доски (например, одну стену).
  • Настройки и версия… — открыть менеджер; Сообщить о проблеме… — отправить журнал разработчику.

Что должно быть в проекте

  • Доски ArchiFrame должны «читаться»: установлен ArchiFrame или проект открыт как .pla с вложенной библиотекой. Иначе плагин скажет «Параметры досок не читаются».
  • Группы = слои досок. Доски не на тех слоях попадут не в ту группу.
  • Для «Листов в Archicad» — мастер-макеты с именами из настроек (нет A3 с таким именем — берётся первый A3 альбомный).
  • Для «Общего PDF» — набор публикации со словом «макет» в названии (или указанный в настройках).

Чего пока нет

  • 3D-видов (общий вид каркаса и виды групп, как на листе 1 образца) — ни в PDF, ни на листах.
  • Дополнительные резы досок (кроме торцевых запилов) не образмериваются — в примечании «доп. резы — см. 3D».

5. Порядок работы над КД

Быстро — только файл

  1. «Только PDF-файл» → PDF откроется сам. Проект не меняется.

Полный комплект в проекте

  1. Сохраните проект.
  2. «Марки и параметры в свойства досок» → в Archicad обновите каталог «КД-СП» (если он есть, см. раздел 6).
  3. «Листы в Archicad» → проверьте листы, при необходимости поправьте руками.
  4. «Общий PDF из готовых листов» → один PDF из всех листов.
  5. Сохраните проект, если всё устраивает.

Каркас поменялся: снова шаги 2–4 (или «Пересоздать листы + общий PDF» вместо 3–4). Помните: ручные правки на листах «КД каркаса (авто)» при пересоздании пропадут.

6. Интерактивный каталог КД-СП

Спецификация, которую Archicad обновляет сам по свойствам досок. Схему каталога через API создать нельзя — один раз на проект (или в шаблоне офиса) её делают руками:

  1. Запустите «Марки и параметры в свойства досок» — появятся классификация и свойства «КД каркаса».
  2. Archicad: Документ → Каталоги → Параметры Схемы… → «Новая…»: ID КД-СП, имя «КД каркаса — спецификация», тип «Элементы».
  3. «Добавить Критерии…» → поиск «КД каркаса» → «Классы / КД каркаса - 1».
  4. «Добавить Поля…» → поиск «КД каркаса» → Марка, Группа, Сечение, Длина мм, Кол-во в марке, Примечание (Σ не включать).
  5. В самом каталоге включите «Объединить Элементы».

Дальше «Листы в Archicad» сами ставят каталог на листы после общей спецификации — кусками по 2 колонки на A3, шапка повторяется. Нет каталога с таким ID — листы строятся без него. ID и высота строки — в настройках.

7. Площади поверхностей

Считает площадь всех поверхностей элементов (для покраски, пропитки) и сохраняет отчёт. Проект не меняется.

  • Папка — куда сохранить (кнопка «…» — выбрать); по умолчанию рядом с проектом (другую папку по умолчанию можно задать в настройках).
  • Имя файла — без расширения.
  • Формат: HTML (+ CSV рядом), Excel (лист «Сводка» с итогом и лист «Элементы» — по одному, числа можно считать), или HTML + Excel. Формат по умолчанию — в настройках.
  • Только выделенные элементы — включено по умолчанию. Без выделения считается вся модель, включая рельеф, перекрытия и т. п. — итог будет огромным.
  • Слой содержит — взять только элементы со слоями, в имени которых есть этот текст.
  • Мин. ширина, мм — отбросить узкие элементы (косоуры, стойки).
  • Толщина досок без библиотеки — только если ArchiFrame не загружен.

Как считается (видно в колонке «метод» отчёта): доски ArchiFrame — по контуру с запилами × своя толщина; перекрытия — верх + низ + кромки; объекты — площадь поверхности из свойств Archicad. «Пласть» — наибольшая грань.

10. Обновление

  • Автоматически: при входе в Windows (ярлык «Обновление плагинов Archicad» в автозагрузке). Окно — только если что-то обновилось или ошибка. Выключается в настройках.
  • Вручную: менеджер → «Версия и обновление» → «Проверить» → «Обновить сейчас» (или «Обновить.bat»).
  • Если Archicad был открыт — в палитре Tapir выберите «Reload scripts…» или перезапустите Archicad.
  • Нет связи с GitHub — менеджер напишет об этом; подробности — в журнале «Обновление», он уходит вместе с «Сообщить о проблеме…».

11. Ошибки и отчёты разработчику

  • Плагин упал — откроется окно «Произошла ошибка»: напишите, что делали, и нажмите «Отправить разработчику». «Открыть журнал» — посмотреть журнал; из него тоже можно «Отправить в Telegram».
  • Не упал, но сделал не то — «Сообщить о проблеме…» (в окне плагина или в менеджере).
  • Уходит в Telegram @lider_house_debug_bot: плагин, версия, проект, компьютер, ваш комментарий, текст ошибки и журнал.
  • Журналы лежат в %LOCALAPPDATA%\ArchicadPlugins\logs\ — если отправка не удалась, пришлите файл вручную.

12. Установка и удаление

  • Установка (один раз на компьютер): скачать последнюю версию (github.com/greyka/archicad-kd-karkas → Releases → Source code (zip)), распаковать, закрыть Archicad, запустить «Установить.bat». Ставит Tapir, uv (Python), копирует плагины в C:\ArchicadPlugins, подключает их к палитре Tapir, создаёт ярлыки. Журнал — %TEMP%\archicad_plugins_install.log.
  • Удаление: закрыть Archicad → «Удалить.bat». Tapir, uv и settings.ini остаются.
